# 论文篇幅与图表视觉规范

## 篇幅判断

2026 年全国大学生数学建模竞赛论文格式规范规定：摘要（含标题和关键词）原则上不超过一页；正文从第四页开始，正文不超过 30 页；附录页数不限。电子版论文应是一个独立的 PDF 或 Word 文件，正文、附录和纸质版内容保持一致，支撑材料另行压缩提交。规范没有规定统一字号、字体、行距和颜色，因此篇幅应由论证完整性决定，而不是靠缩小字体或拉大行距填页。

官方规范：

- [全国大学生数学建模竞赛论文格式规范（2026 年修订稿）](https://www.mcm.edu.cn/upload_cn/node/775/cQMeL0YY905244c8bd4b9af832f1699446d8385e.pdf)

本轮对公开获奖样本做了可复核的页数检查。2023 CUMCM A 国一等奖团队公开的 PDF 共 60 页，正文约到第 26 页，随后进入支撑材料；2020 CUMCM B《沙漠游戏》和 2024 CUMCM A《板凳龙》公开 PDF 的总页数分别为 42 页和 58 页，但其中部分字体编码无法稳定定位正文与附录分界，因此只记录总页数，不把它们当作正文统计样本。

- [2023 CUMCM A 国一等奖：定日镜场优化设计模型](https://github.com/linggm3/2023_CUMCM_National-First-Prize)
- [2020 CUMCM B：沙漠游戏](https://github.com/seanys/CUMCM2020-Desert-Game)
- [2024 CUMCM A：板凳龙运动状态及路线研究](https://github.com/cny123222/CUMCM-2024A-Bench-Dragon)

据此，本稿的编辑目标设为**摘要 1 页以内、正文约 18--24 页、附录独立承载代码索引和支撑材料清单**。这是对规范和公开样本的写作目标推断，不是竞赛组委会公布的“获奖页数阈值”。当前内容扩充优先放在模型推导、算法伪流程、实验协议、误差边界和结果解释上，避免加入不能由题面、代码或日志核验的背景段落。

## 统一配色

图示采用低饱和蓝灰—青绿—暖沙方案，颜色同时配合线型、点型和文字标签使用。这样在彩色屏幕、黑白打印和色觉差异下都能保留语义。Tableau 的可访问性建议强调颜色对比度、不要只依赖颜色区分、并使用形状和线型辅助识别；可参考 [Tableau accessibility best practices](https://help.tableau.com/current/pro/desktop/en-us/accessibility_best_practice.htm) 和 [Accessible Color Sequences for Data Visualization](https://arxiv.org/abs/2107.02270)。

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| ink | `#263238` | 正文线条、坐标轴、主要文字 |
| navy | `#365F7C` | 主路线、核心模型、关键点 |
| teal | `#4F7C82` | 辅助站点、可行反馈、正向状态 |
| sage | `#7D9A86` | 次要可行区域 |
| sand | `#C99653` | 信息收益、比较指标 |
| coral | `#B9685D` | 风险、清除动作、阈值提醒 |
| mist / paleBlue / paleTeal / paleSand | `#EEF3F4` / `#E4EEF3` / `#E6F0EE` / `#F5ECDD` | 图示节点填充和浅色区域 |

图表的具体约定为：一幅图只表达一个主要结论；双面板用 `(a)`、`(b)` 说明视图功能；图例放在空白区域，不压住数据；数字标注通过偏移量放在数据点外侧；所有输出保留 SVG 和 300 dpi PNG，并用灰度预览和布局审计复核。

## 版式检查清单

1. 正文页数以 Overleaf 最终 PDF 的摘要页后页码为准，不能用源文件行数代替。
2. 摘要只保留问题、方法、主要结果和证据边界；详细参数和代码放在正文相应小节或附录。
3. 每个表格和图都在正文中先解释用途，再给出结果；表下注明数据来源和“本地验证/官方演练”的证据等级。
4. 流程图节点等宽、箭头标签留白，避免将标签放在节点边框或箭头交叉点上。
5. 正式提交前重新编译、检查引用和图表编号，并确认匿名版不含队号、学校、成员和账号信息。
