# 五分钟理解 B 题

[返回首页](../README.md) · [完整模型](model.md) · [实验结论](results.md)

我们已得到一套有覆盖证明、能完整运行、经过官方策略组演练的方案。当前 q3 默认使用 `adaptive_q25`：完整策略组中合并单源时间最低；`adaptive_q10_dynamic` 作为总时间较低的研究对照保留。结果仍不能用于预测正式成绩或奖项。

## 1. 背景与目的

题目研究无线电干扰源的自动定位与清除，希望让机器狗携带测向和光学设备，完成需要人员进入目标区域排查的任务。半径 **1800 m** 的圆形区域内有 **10–16 个**固定干扰源，位置、实际总数及接收半径未知。机器狗从圆心出发，检测不同频道获得带误差的方向信息，接近到 **20 m** 内后进行光学定位和清除。

目标是确保全部清除，并尽量减少总虚拟时间。第四问还包含只向一个闭半平面发射的定向源，因此“没有信号”可能意味着位置不对、距离太远、方向不可见，或该频道没有源。

## 2. 输入与输出

这是边观测、边决策的交互问题，不是一次性读入隐藏源坐标求路线。

| 问题 | 输入 | 输出 |
| :--- | :--- | :--- |
| 1 | 多个检测位置、同一源的测向角、误差界 | 定位区域、直径算法、直径圆是否覆盖的结论 |
| 2 | 首个检测位置及测向角 | 第二个检测点的候选区域与选点方法 |
| 3 | 题设规则及逐次反馈；源均全向 | 搜索、定位与清除策略，完成证据和耗时 |
| 4 | 第三问的信息，另含未知类型与方向 | 能处理方向盲区的策略及结果记录 |

每步选择“位置 + 频道”，得到 `direction`、`near` 或 `no_signal`，更新可能位置，再决定下一步。角度误差界为 ±1°；实现为接口小数精度预留余量，采用 ±1.01°。策略只接收合法接口反馈，源真值只存在于合成环境或官方模拟器。

## 3. 指标与当前水平

$$\text{清除比例}=N_{\mathrm{clear}}/N,\qquad \text{平均定位清除时间}=T_{\mathrm{virtual}}/N_{\mathrm{clear}}.$$

首先检查是否全部清除，再评价每源耗时。总时间包含移动、切换频道、测向、光学尝试及清除，也包含确认没有遗漏的巡检。虚拟时间与程序运行时间不同。

| 历史主方案官方演练 | 三局 q3 清除结果 | 每源虚拟时间（秒） |
| :--- | :--- | :--- |
| 第三问 · 七站 | 15/15、12/12、13/13 | 368.57、406.26、395.72 |
| 第四问 · 三角网格 28 站 | 14/14、10/10、15/15 | 1045.72、1086.38、850.42 |

加上旧方格方案的一局，共 **7 局、92/92 个源清除**。第三问三局平均 **390.18 秒/源**，第四问主方案平均 **994.17 秒/源**。106 个本地合成运行全部完成，支持实现与边界处理的可靠性；这些数据不能证明所有场景成功，也不能映射为某个奖项。

最新 q3 策略组报告纳入 8 个策略、25 个完整演练记录。`adaptive_q25` 的合并单源时间为 303.224 秒/源，低于 `adaptive_q10_dynamic` 的 349.065 秒/源；后者的总虚拟时间最低，但平均清除数较少。完整表见 [策略组汇总](../results/practice/q3_official_strategy_summary_20260911.csv) 和 [测评报告](../reports/q3_official_practice_report_20260911.md)。

## 4. 建模方案与改进

总体方案是 **有界误差几何定位 + 全域覆盖证明 + 动态访问调度**。

| 环节 | 方法 | 作用 |
| :--- | :--- | :--- |
| 可能位置 | 多次测向楔形相交，圆盘用保守外包 | 不因测量误差过早排除真位置 |
| 清除判定 | 最小包围圆半径 ≤ 19.75 m | 保证可能位置落入 20 m 清除范围并保留余量 |
| 再测向 | 最坏线性化误差代理 + 移动惩罚 | 兼顾信息质量和路程 |
| 全向搜索 | 原点与六个外围站 | 保证每个全向源距某站 ≤ 900 m |
| 定向搜索 | 28 站三角网格覆盖 | 保证任意发射闭半平面内至少有一个可接收站 |
| 定位兜底 | 与剩余区域相交的 25 m 方格中心 | 测向困难时仍有有限清除路径 |

第一问的关键反例是边长 39 m 的等边三角形：直径只有 39 m，但最小包围圆半径约 22.52 m，所以“直径 ≤ 40 m”不足以保证一次清除。

第四问把 **49 个方格覆盖站改为 28 个三角网格站**。每个源属于边长 950 m 的覆盖三角形；任意闭发射半平面至少包含一个顶点，该顶点离源不超过 950 m。覆盖站减少，但定位仍会产生额外检测点。配对合成对照为：q3 固定到动态降低 4.30%，q4 三角固定到动态降低 6.64%，q4 动态方格到三角降低 **17.11%**。三个百分比来自不同对照，不能相加，也不代表领先其他队伍。

三轮第四问主方案演练走了约 43–61 km，移动占虚拟时间约 80%–87%；下一步优先优化移动路径、失联换点和光学兜底。
